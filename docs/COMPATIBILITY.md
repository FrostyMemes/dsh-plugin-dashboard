## Текущее решение и следующий проверяемый шаг

Исходники плагина реализуют pairing-путь из утверждённого плана: кнопка Bundle запрашивает у Host Remote случайный одноразовый токен с TTL 2 минуты; токен передаётся во fragment URL; API обменивает его на подписанную HttpOnly/SameSite cookie с TTL до 30 дней, привязанную к `127.0.0.1:<port>`. Cookie signing key хранится через DSH Credentials. SPA, snapshot и SSE обслуживаются собственным loopback prefix route. Самостоятельный route проверяет Host, Origin и Fetch Metadata, а защищённые API дополнительно проверяют cookie. Исправленный `cordis.patch.yml` использует подтверждённый `- insert:` формат; Client entry собирается в формат `window.__ModuleLoader__.load(...)`.

Совместимость проверена частично. Первоначальный компонент доходил до `Running`, но pairing завершался обычным `Error`. Затем startup dialog выявил циклическое ожидание `remote.agentControlCenter`; оно устранено в исходнике: namespace монтируется первым, detail action регистрируется в дочернем fiber после его появления. После перезапуска пользователь подтвердил скриншотом успешный pairing: статус `Connected`, snapshot с одним root agent в состоянии `idle`, известные subagents `0`, четыре token counters (input `7 520`, output `196`, cache read/write `0`, всего `7 716`), модель `deepseek-v4.1-flash`, context estimate `7 690 / 1 000 000`; задача корректно отображается как недоступная, snapshot помечен `Partial`. Метка `Connected` устанавливается обработчиками EventSource `onopen`, `heartbeat` и `snapshot`, что подтверждает открытие SSE и получение начального snapshot. Пользователь затем подтвердил, что live-обновление активной сессии появилось на дашборде. Reconnect после потери потока пока не проверен.

## Ограничения этой проверки

- Проверена одна установка `0.2.0-rc.2`; совместимость с другими версиями не заявляется.
- API и большая часть поведения исследованы по точным файлам поставляемого ASAR и source tag; локальный Bundle установлен, включён и показывает активный компонент.
- Pairing, подписанная cookie, первоначальный snapshot, открытый SSE и live-обновление активной сессии подтверждены скриншотом и сообщением пользователя после исправления circular injection. Не проверены reconnect/resync после разрыва, остановка/повторная активация Bundle, сценарий с подагентом и полнота token meter. Задача, отсутствующая в безопасном источнике, корректно остаётся недоступной; snapshot сообщает `Partial`.
- Декларации типов могут отсутствовать в поставке ASAR; для разработки надо взять совместимые опубликованные типы/пакеты и привязать их к версии `0.2.0-rc.2`, не считать отсутствие `.d.ts` доказательством отсутствия runtime API.
- Установленная версия отличается от текущего upstream `master`; API проверять по установленным файлам и зафиксированному tag.
